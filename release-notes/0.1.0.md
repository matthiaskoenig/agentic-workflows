# Release notes for agentic-workflows 0.1.0

First version of the agentic workflows site, https://matthiaskoenig.github.io/agentic-workflows/. The site is the teaching and onboarding resource for how we work with coding agents.

## Features
- site built with zensical from markdown in `docs/`, deployed to GitHub Pages from `main`
- introduction to agentic coding: from autocomplete to agents, the loop, six concepts for a first session, a self-study sequence and a curated resource list
- getting started guide with an onboarding checklist, a setup checklist of everything to install on a computer and in a repository, and a guide to onboarding a repository
- concept pages: harnesses, models, `CLAUDE.md` and `AGENTS.md` instruction files, skills, orchestration
- best practice pages: the development loop, token maxing, engineering standards, Python code (ruff, ty, pydantic), repository policies
- tooling and resources pages, and an open questions page for what is not settled yet

## Development
- `CLAUDE.md` with build commands, layout and writing rules for agents working on the site
- branch protection of `main` as a ruleset in `.github/rulesets/main.json`, applied with `apply.sh`: pull request required, `build` check, linear history, no bypass
- the `build` job of `docs.yml` runs on every pull request, the deploy only on `main`
- `tests/test_docs.py` checks the strict build, the navigation, internal links and the writing rules; `tests.yml` runs pytest, ruff and ty as the required checks `tests`, `ruff` and `ty`
- releases are tagged and described in `release-notes/<version>.md`
