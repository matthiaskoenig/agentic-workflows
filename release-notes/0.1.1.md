# Release notes for agentic-workflows 0.1.1

Patch release of the agentic workflows site, https://matthiaskoenig.github.io/agentic-workflows/. It adds the pages written since the first version, restyles every diagram, and documents hooks and the browser setup.

## Features
- introduction page: from autocomplete to agents, the loop, six concepts for a first session, what not to start with, a 90-minute self-study sequence and a curated resource table
- setup checklist page: everything to install on a computer and in a repository, commands only, including the code intelligence plugins `pyright-lsp` and `typescript-lsp` and the Claude in Chrome browser extension
- Claude Code commands page: the commands we use, when we reach for them and where each one is documented
- open questions page: voice programming, overnight runs, settings files, herdr on all machines, tokens and team members, multiple accounts, one harness for all models, and the tools mentioned but not yet evaluated
- instruction files page: the video "Writing a CLAUDE.md That Claude Actually Follows" is embedded, and a new section explains hooks and how to move hard rules out of the instruction file into a `PostToolUse` hook
- harnesses page: Claude Code is the main harness, Codex gives second opinions, OpenCode and pi are under evaluation
- tooling page: code intelligence plugins, the browser section, and links to the interactive context window timeline and the reduce-token-usage guide from the token maxing page
- diagrams: every mermaid flowchart uses one shared style from `docs/includes/mermaid-classes.mmd`, with thin colored strokes, translucent fills that work in light and dark mode, straight edges, and one color per concept (people, harness, model, context, skills, tools, artifacts, decisions); the legend is on the home page
- setup page: keep Google Chrome open with the Claude in Chrome extension whenever the agent works on a web page, so it validates changes in the real browser; the session tools list a terminal multiplexer instead of a specific one

## Development
- agent instructions moved to `AGENTS.md` with `CLAUDE.md` as a symlink, trimmed to what the tests and the code do not already say, and extended with the diagram convention
- `pymdownx.snippets` enabled with `docs/includes` as base path and path checking, so a missing include fails the strict build
- `docs.yml` no longer runs `actions/configure-pages` in the build job, which had failed the first deployment
- README wording cleaned up: opinionated, based on our workflows, updated continuously, changes go through a pull request
